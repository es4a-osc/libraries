# XQRC二维码库

为 Simple 提供 `XQRC二维码`、`XQRC扫码框`、`XQRC二维码配置`、`XQRC扫码配置`和`XQRC识别结果`，支持普通、图标和艺术背景二维码、图片识别、独立扫码页及内嵌相机预览。异步任务以请求序号返回结果，可取消并丢弃过期回调。

- 生成结果为 PNG 字节数组；输入支持资产、绝对文件、`file://`、`content://` 和图片字节。压缩图像上限 32 MiB，读取时采样到最长边 2048 像素；小码可能需要先裁剪原图。
- 相机扫描需要相机权限及可用设备，组件负责请求权限；同一时刻只允许一个真实预览。补光、对焦、声音和振动受硬件及系统设置限制。
- 系统选图使用文档选择器的内容 URI；直接读取外部文件仍需应用取得对应访问权。识别不会自动打开链接。
- ZXing 使用本库私有包名，不与旧条码库的 ZXing 冲突；本库不包含原生库。与旧条码库共用时，旧库的 ARM 32 位原生功能限制仍然存在。
- 独立扫码页支持原生 Activity 主题资源和提示文字；0 使用默认主题。自定义 Simple 布局使用内嵌扫码框，不接入 Fragment 宿主。
- 可手动请求对焦并接收设备实际完成结果；查询扫描框、预览解码区域及独立扫码状态。未开启相机时预览区域为空，对焦请求不受理。实时候选点仅辅助定位，不表示识别成功。
- 配置可复制为独立快照。`XQRC二维码调试` 提供默认关闭的 Logcat 调试开关，建议只在开发时开启。

成员说明见源码注解及清单，常见操作见 [example](example/)。
