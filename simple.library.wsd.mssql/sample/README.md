# MsSQL数据库类库示例

文档类型：使用示例。核对日期：2026-10-15。依据：本库公开接口、`library.json`、原例程以及当前 Simple 编译器和运行库。适用范围：本目录的 `project.properties`。

先构建本库；实际使用时通过类库仓库 `release.bat` 安装到选用的 SDK，再在 ES4A 中选择该 SDK 入口、刷新类库并添加本目录的 `project.properties`。本次构建验证使用隔离的类库目录，没有修改 SDK 安装目录或入口。

1. 将预留示例地址 `192.0.2.1:1433`、库名、用户名和密码改为自己的测试数据库，使用具有对应权限的 SQL Server 测试账号。
2. 连接成功后运行默认 `SELECT 1 AS value`。`查询语句` 的第二个参数为空表示返回全部列；也可传如 `id,name` 的列名列表。
3. 若要体验增删改，先在测试库手动创建下方 `es4a_demo` 表；三个按钮只操作该表的 `id=1`。
4. 新增后将查询框改为 `SELECT id,name FROM es4a_demo` 查看，再分别修改、删除。
5. 点击断开。

```sql
CREATE TABLE es4a_demo (id INT PRIMARY KEY, name NVARCHAR(64));
```

保留原库“0 行返回假”的写入结果，不能仅凭假判断是否出现 SQL 异常。异步操作在主线程回调，直接返回结果的同步接口会阻塞调用线程。SQL 片段由调用方构造并校验；不默认使用 sa 账号。

已验证：Java 构建、清单加载、成员与继承、签名、SVG 和设计器候选消费、真实 Simple 示例生成 APK。未验证：真实扩展宿主可见交互、Android 真机及实际设备或服务器行为。
