# OTG通讯库示例

文档类型：使用示例。核对日期：2026-10-15。依据：本库公开接口、`library.json`、原例程以及当前 Simple 编译器和运行库。适用范围：本目录的 `project.properties`。

先构建本库；实际使用时通过类库仓库 `release.bat` 安装到选用的 SDK，再在 ES4A 中选择该 SDK 入口、刷新类库并添加本目录的 `project.properties`。本次构建验证使用隔离的类库目录，没有修改 SDK 安装目录或入口。

1. 手机连接匹配的 CH34x 串口转换器，并确认 OTG 供电和 USB Host 支持。
2. 点击“打开设备”，系统弹出 USB 授权时同意，再点一次打开。
3. 设置波特率，点击“设置参数 8N1”；示例使用单参数重载，默认 8 数据位、1 停止位、无校验、无流控；完整四参数接口仍可用。
4. 发送框输入如 `4C 5D`，点击发送；日志显示驱动写入长度和接收字节。
5. 点击关闭，可再打开。接收事件是数据片段，业务协议需自行组帧。

`到十六进制` 保留小写和每字节后空格；`到字节集` 忽略空白、奇数位末尾补零，无效字符会拒绝。转换长度越界会拒绝，不静默截断。

已验证：Java 构建、清单加载、成员与继承、签名、SVG 和设计器候选消费、真实 Simple 示例生成 APK。未验证：真实扩展宿主可见交互、Android 真机及实际设备或服务器行为。
