# MQTT通讯库示例

文档类型：使用示例。核对日期：2026-10-15。依据：本库公开接口、`library.json`、原例程以及当前 Simple 编译器和运行库。适用范围：本目录的 `project.properties`。

先构建本库；实际使用时通过类库仓库 `release.bat` 安装到选用的 SDK，再在 ES4A 中选择该 SDK 入口、刷新类库并添加本目录的 `project.properties`。本次构建验证使用隔离的类库目录，没有修改 SDK 安装目录或入口。

1. 将预留示例地址 `tcp://192.0.2.1:1883` 改成自己的测试代理地址；按需填写账号、密码和主题。
2. 点击连接，收到“连接成功”后点击订阅。
3. 收到“订阅成功”后点击发送，示例发布 ASCII 字节 `Simple`，QoS 1、不保留；日志显示接收主题、长度和 QoS。
4. 可取消订阅或断开。自动重连成功也会再次触发连接成功；清除会话为真时需重新订阅，应用自行决定。
5. `关闭服务()` 永久终止此组件，需要继续使用时创建新的组件。

示例不请求电话权限；客户端 ID 通过兼容接口取得替代标识。多个实例请传入各自唯一的 ID。`READ_PHONE_STATE` 仅供旧系统可选的设备标识读取，MQTT 通讯本身不要求授予该危险权限。发送及取消订阅在未连接或调用失败时抛出异常，应用应按连接状态调用；发送完毕不是业务处理确认。

已验证：Java 构建、清单加载、成员与继承、签名、SVG 和设计器候选消费、真实 Simple 示例生成 APK。未验证：真实扩展宿主可见交互、Android 真机及实际设备或服务器行为。
