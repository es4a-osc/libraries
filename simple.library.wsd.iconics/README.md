# 字体图标库

基于 [Android-Iconics](https://github.com/mikepenz/Android-Iconics) 封装，提供字体图标、图标控件、文字混排、自定义字体、组合动画和 PNG 输出，附带配套字体。

需要 Android 7.0（API 24）及以上，字体和视图在主线程使用。自定义图标映射限 Unicode BMP；字体名称和字符映射以随附版本为准，完整字体集合会增加应用体积。

切换窗口或进入后台会自动暂停动画。相对布局受应用 RTL 设置影响；PNG 保存目录须已存在。

## 依赖来源
