# 字体图标库

基于 Android-Iconics 5.3.0，提供字体注册、图标绘制、七类图标控件、文字混排、状态颜色、组合动画和 PNG 输出。包含官方配套字体及 XUI 示例的 17 个图标。

使用 JDK 11、Android API 30 编译，最低 API 24。公开类型位于 `simple.library.wsd.iconics`；可视组件位于“扩展可视组件”，动画控制位于“扩展组件”。

字体和视图操作使用主线程。自定义字体前缀为三个小写字母或数字，图标映射限 Unicode BMP；注册后映射不可修改，重复前缀拒绝覆盖。图标名支持 `xui_emoj` 和 `xui-emoj`。尺寸使用 DIP，字号使用 SP。样式在应用时复制，修改配置需重新创建或应用图标。保存 PNG 的父目录须已存在，相对路径基于应用内部文件目录。

动画绑定目标后添加配置；类型 0 为旋转（度），1 为透明度（0–255），2 为缩放（非负比例）。切窗或进入后台自动暂停，返回时只恢复自动暂停的动画；手动暂停保持暂停。销毁组件终止动画并释放监听。动画事件在当前操作完成后由主线程异步通知，清空、重绑或销毁丢弃尚未送达的旧通知。文字内嵌图标使用 `{xui_chat}` 格式，可通过图标文字构造器设置统一或逐图标样式。

各字体的名称和字符映射以所附固定版本为准，可通过图标工具查询；字体自身的授权信息可从图标字体对象读取。完整字体集合会增加应用体积。此库无需 XUI、Fragment 或独立 Activity。

四侧附图支持绝对位置及起始/结束相对位置，常态与选中态分别维护；切换坐标系保持当前视觉位置。库清单声明 `supportsRtl=true`，启用应用 RTL 支持；若应用显式禁用 RTL，相对布局会受该设置限制。可读取或清除图标与附图、设置图文间距和图片缩放。图标直接应用到实际视图，运行库的图片或背景路径属性不表示字体图标；读取当前图标请使用本库的快照接口。

图标可批量创建、绘制同字体短文字，并支持整体状态着色及20项颜色矩阵滤镜。图像和样式读取返回独立快照；原生状态颜色快照可查询，需清空后重新配置条目。

动画编号稳定，移除其他项不改变编号，清空也不复用旧编号。可按编号启动、暂停、继续、取消、结束、反向、移除，以及定位进度或播放时间、读取当前值和配置、输出当前组合帧PNG。目标图像被替换后停止对应动画；再次播放须重新绑定；可主动解除绑定释放目标引用。
