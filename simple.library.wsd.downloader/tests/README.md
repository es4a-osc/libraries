# 下载器验证

文档类型：测试说明与验证记录。核对日期：2026-10-17。依据：当前类库源码、本机真实 HTTP 回归、配套示例 APK 与 Escrcpy MCP 设备操作。主机回归和 APK 设备测试分别记录。

## 可重复的主机回归

在本类库目录运行 `powershell -ExecutionPolicy Bypass -File tests/run.ps1`。脚本构建类库，使用项目配套 JDK 8 编译并运行 `DownloadEngineTest`；测试数据位于本库 `build/http-test-*`，不访问外部下载站。受限环境需要允许本机回环 socket。

已通过 29 项检查：普通文件内容、完成字节数、目标不覆盖、非法编号和协议、暂停后停止写入、稳定编号、Range 续传、立即暂停继续、忽略 Range 后完整重下、错误 Content-Range 和文件标识变化拒绝发布、404、截断、未知长度、重定向、超过 2GB 的长度字段、取消清理和回调隔离、重启恢复及文件内容。

超过 2GB 的检查只验证响应长度字段和状态保存不溢出，没有实际下载 3GB 文件。Java 内存 Store 用于主机回归；Android SQLite 记录由下述设备测试验证。
