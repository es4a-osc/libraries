# 下载器库

提供非可视组件 **下载器**，支持 HTTP/HTTPS 文件下载、暂停、继续、取消和应用私有断点记录，无第三方依赖。

将已编译类库安装并注册到所选 SDK，在窗口中添加“下载器”组件即可使用。网络权限由组件注解声明；使用者无需重新编译 Java 源码。

- [类库清单](library.json)：方法、事件及参数类型。
