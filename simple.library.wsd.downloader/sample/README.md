# 下载器示例

本使用说明依据当前下载器接口、传输实现及配套示例核对（2026-10-18），适用于 `simple.library.wsd.downloader` 的 HTTP/HTTPS 下载功能。

在 ES4A 添加本目录的 [project.properties](project.properties)。先将已编译下载器库安装并注册到所选 SDK，清单与实际 `classes.jar` 必须配套；示例代码见[主窗口](src/simple/library/wsd/downloader/sample/主窗口.simple)。默认下载 `https://www.example.com/` 到应用私有 `downloads/example.html`，外网可达性由实际网络决定。

## 操作

1. 输入 HTTP/HTTPS 网址及保存路径，点击“开始下载”。相对路径位于本应用内部文件目录，无需存储权限。
2. 用较大文件观察进度，点击“暂停”“继续”；暂停和取消不会触发完成事件。
3. 暂停后退出、重新进入示例，点击“继续”。本例一次管理一个当前任务，切换来源或保存目标前先取消未完成任务。
4. 点击“取消”后临时文件在任务收尾时删除；已经完成的文件保留。目标存在时请改用新的文件名。
5. 点击“读取未完成记录”，查看等待、下载、暂停和失败任务的数量。

## 任务与结果

任务编号从 1 开始，跨应用重启保留，不是集合下标；相同网址与目标的未完成任务继续原任务。同网址不同目标可以是不同任务，不存在的编号会抛出错误。

上次任务编号保存在应用设置，类库在应用私有 SQLite 中保存全部任务。多个组件实例共享任务列表并收到各任务事件，本示例按当前编号筛选。内部最多同时传输两个任务，其余排队。

`取任务信息` 返回六项文本数组，索引 0 至 5 依次为网址、保存绝对路径、状态、总字节数、已下载字节数、错误说明。总大小和进度百分比未知时为 -1。进度及完成事件在主线程触发；失败原因从任务信息读取。

## 文件与续传

相对保存路径基于应用内部文件目录，不能越出该目录；绝对路径需要实际访问权限，组件不自动申请存储权限。只接收普通文件路径，不能直接传入 `content://` URI。缺失的父目录自动创建，已存在目标文件拒绝覆盖。

下载分块写入同目录临时文件，完整后再发布目标文件。暂停保留断点；取消未完成任务会清理临时文件，传输尚未收尾时延后清理。暂停或取消会阻止后续写入，但阻塞中的网络请求可能等待读返回或超时后才结束。

续传使用 Range/If-Range，并核对强 ETag 或 Last-Modified。服务器不支持续传或缺少可验证标识时重新下载；响应范围、文件标识或长度异常时报告失败并保留断点。没有配套测试服务时，可先验证普通下载、已存在目标保护和状态反馈。

HTTPS 使用系统证书校验，拒绝向 HTTP 降级重定向；最多跟随五次重定向，连接和读取超时均为 10 秒。

## 生命周期与范围

最后一个下载器组件销毁或应用正常退出时，活动任务暂停并保存断点。进程异常终止后，重新创建组件会将记录恢复为暂停；调用继续，或以原网址和原路径开始下载，即可恢复。清空应用数据会清除任务记录。

本库不启动常驻或前台服务，不保证进程终止后继续下载，也不提供系统通知、自动重试、更新检测或 APK 安装。

应用更新可将目标改成 `downloads/update.apk`，完成后由应用另外校验可信来源提供的 APK 摘要或签名并处理安装。下载完成和 HTTP 长度检查不能代替这些校验；本示例不执行安装或连接更新服务。
