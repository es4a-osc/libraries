# LuaJ脚本库

基于 [LuaJ](https://github.com/luaj/luaj) 封装，提供 Lua 5.1 脚本执行、值与表、函数、多返回值、协程和 Simple 同步回调，不依赖原生库。

耗时脚本须放在后台，LuaJ 引用不能跨实例混用。协程及宿主回调中不能创建或重入其它实例，也不能等待另一线程调用 LuaJ；挂起协程须恢复至结束，不提供强制中断能力。

脚本与应用共享进程和权限，不是安全沙箱，不直接支持 Lua C 扩展。Lua 数值采用双精度，大整数可能丢失精度。

## 依赖来源

- [LuaJ 2.0.1](https://github.com/luaj/luaj)
