# LuaJ脚本库

基于 LuaJ 2.0.1，提供 Lua 5.1 脚本执行、值与表、函数、多返回值、协程、缓冲区和 Simple 同步回调。全部导出类型使用 `LuaJ` 前缀，均为普通对象；不依赖原生库。

创建 `LuaJ实例` 后可加载或执行代码。加载只编译，执行及函数调用返回 `LuaJ参数`，保留中间和末尾 nil；结果索引从 1 开始。值、表、函数和参数不能跨实例混用。对象由 Java 管理，无需释放原生引用。

同步操作在调用线程执行，耗时脚本须放在后台。多个实例的顶层操作统一串行；宿主回调在实际 Lua 执行线程调用，可使用所属实例，协程及宿主回调内不能创建或重入其它实例，也不能等待另一个线程调用 LuaJ。挂起协程须自行恢复至结束；本库不提供强制中断脚本或关闭挂起协程的能力。

LuaJ 2.0.1 在改变元表弱引用模式时可能返回另一张表，调用 `置元表` 后须使用返回对象。文本边界采用 UTF-8；二进制数据使用字节集。Lua 数值采用双精度，长整数可能丢失精度。加载、运行和转换失败抛出 `LuaJ错误`，实例可读取最近一次错误说明。

文件加载支持绝对路径及相对应用私有 `files` 目录的路径；其它文件访问和 Java 互操作受应用权限限制。脚本与应用共享进程和权限，不是安全沙箱；不直接支持 Lua C 扩展。

## 依赖来源

- [LuaJ 2.0.1](https://github.com/luaj/luaj)：纯 Java Lua 5.1 解释器

[LuaJ脚本示例](example/project.properties)按代码与文件、类型转换、表与环境、运算比较、函数与回调、协程、缓冲区、实例隔离分为八个主题，覆盖全部导出函数及类型常量。
