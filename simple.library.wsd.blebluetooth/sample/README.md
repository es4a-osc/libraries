# 低功耗蓝牙样例

先将低功耗蓝牙库及[分组列表框库](../../simple.library.wsd.grouplist/)构建并发布到所选 SDK，再运行本项目。需要支持 BLE 的 Android 真机及可连接的 BLE 外围设备。

1. 开启系统蓝牙与定位，点击“开始搜索”并允许定位权限。10 秒后自动停止，也可手动停止。
2. 点击设备列表中的设备，等待连接和服务发现。展开服务，点击特征，查看 UUID 及读写、通知能力。
3. 点击“读取”，或输入设备规定的十六进制数据后点击“写入”。每字节两位，如 `2C 5B`；支持大小写和空白分隔，不能包含 `0x` 前缀。不默认发送任何命令。
4. 类库在服务发现后自动请求订阅支持通知或指示的特征；接收的数据与读写结果显示在日志中。
5. 点击“断开连接”后可重新搜索或连接。返回退出及程序销毁时释放扫描和连接资源。

本示例按当前编译器的 `targetSdkVersion=26` 申请定位权限。若提高目标 API，须按 [Android 蓝牙权限说明](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions)调整扫描和连接授权，不能直接沿用本示例的授权判断。授权后仍搜不到设备时，检查系统定位开关、设备是否正在广播、距离及是否已被其它应用连接。

UUID 和可写特征均来自设备实际提供的 GATT 服务；写入内容、长度、是否需要配对以及应用协议由外围设备决定。只有设备回调成功后才记录读写成功，通知请求也不等于设备已经接受订阅。不要向不了解用途的特征写入数据。

参考桌面 BLE 例程移植，使用当前 Simple 的事件、集合及组件接口；特征通知能力使用 `是否可通知` 判断。项目可编译，蓝牙连接、读写和通知仍需使用实际设备验证。
