# GIF图片框库

提供可视组件 `simple.library.wsd.gif.GIF图片框`，支持本地 GIF 载入、播放、暂停、继续、停止、清空、循环和缩放。使用方式及设备自检见[独立示例](sample/)。

- `图片` 接受资产名、`@raw/名称`、`@drawable/名称` 或绝对文件路径；`载入字节图片` 接受 GIF 文件字节集。新请求覆盖旧请求，只派发最新请求的成功或失败事件，失败保留原图。空图片路径清空内容。
- 读取和平台解码在单工作线程进行，事件及公开调用在界面线程执行。`自动播放` 只影响之后成功载入的图片；`循环播放` 为真时持续循环，为假时播放一轮并派发完成事件，覆盖文件内的循环次数。单帧 GIF 按静态图显示。
- 暂停保留位置，继续从当前位置播放，停止回到第一帧，开始从头播放。组件隐藏、离开窗口或应用进入后台时冻结进度，再可见时恢复此前的播放意图；用户暂停的图片不会因此自动播放。
- 无需额外 JAR、随库原生库或组件权限。资产、资源、字节和本应用私有文件无需存储权限；其它文件取决于应用已有访问条件。不直接下载网址或读取 content URI。
- 输入限 8 MiB、宽高各 2048 像素、512 帧，画布面积乘帧数不超过 16777216；这些是入口限制，不保证实际内存上限。只接受完整 GIF 容器；损坏或不受平台支持的数据通过失败事件反馈。
- 清空和销毁取消请求及刷新，移除组件持有的图像引用。正在执行的平台解码无法强制中断，过期结果会被丢弃；平台原生内存由系统回收，不承诺立即释放。销毁后不能再次写入，应创建新组件。
- 播放使用 [Android Movie](https://android.googlesource.com/platform/frameworks/base/+/master/graphics/java/android/graphics/Movie.java) 和软件画布，兼容当前工具链；该平台 API 已弃用。尚未接入新的动画解码后端，不支持逐帧定位、倍速、APNG 或动画 WebP。
