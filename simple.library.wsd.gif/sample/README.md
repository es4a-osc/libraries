# GIF图片框示例

使用包含本类库的编译环境编译本目录 project.properties，运行后观察动画和实时状态。

1. “资产动图”“资源动图”“字节动图”“文件动图”分别演示四种载入方式。文件示例只写入本应用私有目录，无需存储权限。
2. “从头播放”“暂停”“继续”“停止”“清空”分别观察位置推进、冻结、恢复、回零和内容移除。
3. 关闭“循环开关”后从头播放，观察播放完成事件与最后一帧；“缩放方式”依次切换等比、拉伸和原始像素居中。
4. “隐藏显示”及应用前后台切换用于核对不可见暂停；点击图像查看单击事件。
5. “坏图测试”显示失败反馈并保留原图；“快速切换”连续提交三个请求，只应收到最后一个动画的结果。
6. “重建组件”取消旧实例并创建新实例；“运行自检”是辅助入口，自动核对载入、时钟、错误保持、取消和播放完成，结束后恢复演示。

sample/assets 中的动图及 sample/res/raw/gif_demo.gif 为确定生成的几何色块，字节示例也由相同规则生成，无外部图片授权依赖。单帧与完整格式支持边界、输入大小限制及资源回收约定见[类库说明](../README.md)。
