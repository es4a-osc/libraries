# 蓝牙打印机库示例

文档类型：使用示例。核对日期：2026-10-15。依据：本库公开接口、`library.json`、原例程以及当前 Simple 编译器和运行库。适用范围：本目录的 `project.properties`。

先构建本库；实际使用时通过类库仓库 `release.bat` 安装到选用的 SDK，再在 ES4A 中选择该 SDK 入口、刷新类库并添加本目录的 `project.properties`。本次构建验证使用隔离的类库目录，没有修改 SDK 安装目录或入口。

1. 点击“请求权限”并确认系统授权，再请求开启蓝牙。
2. 列出已配对设备，或搜索附近设备；未配对时按系统提示配对。Android 6-11 搜索还可能要求定位服务开启。
3. 将目标打印机 MAC 地址填入地址框并连接，收到连接成功后再打印。
4. “打印测试文本和条码”演示重置、字号、粗体、下划线、反白、对齐、GBK 文本、Code128 和走纸。条码内容以 `{B` 指定 Code128 B 代码集；仍需型号支持。
5. 点击断开。关闭蓝牙接口打开系统设置，由用户关闭手机蓝牙，不强制修改系统开关。

`assets/test.png` 保留原例程图片；应用取得图片字节集后可调用 `蓝牙打印机1.图片(图片数据, 380, 190)`。当前运行库没有旧例程的资源文件读取函数，样例未伪造同名 API。图片尺寸上限各为 4096，建议按实际纸宽缩放。扫描或读取设备前须授权，拒绝授权不会被当成搜索成功。

已验证：Java 构建、清单加载、成员与继承、签名、SVG 和设计器候选消费、真实 Simple 示例生成 APK。未验证：真实扩展宿主可见交互、Android 真机及实际设备或服务器行为。
