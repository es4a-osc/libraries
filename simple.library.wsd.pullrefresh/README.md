# 拉动刷新框库

提供“拉动刷新框”可视容器，在内容顶部下拉或底部上拉达到阈值并松手后，分别发出“下拉刷新开始”“上拉刷新开始”事件。组件不自动读取数据，具体业务由应用处理，完成后调用 `停止刷新()` 收回提示；此方法不取消业务任务，也不表示业务成功。

子组件直接放入本容器，布局沿用 Simple 面板规则；有子组件后不能更换布局类型。内容统一由外层纵向滚动，适合标签、图片、按钮和组合面板。嵌套列表或网页等可滚动控件时，需安排好高度与触摸区域。短内容也允许上下拉。

`允许下拉`、`允许上拉` 默认启用，可分别关闭；关闭当前方向会结束该方向的操作。`正在下拉刷新` 表示下拉操作等待完成，`正在上拉刷新` 表示上拉操作等待完成，两者互斥。所有界面操作均在主线程执行。

上下拉各有“提示文本”“释放文本”“处理文本”，对应未达阈值、达到阈值等待松手、正在等待业务完成三个状态；还可分别设置“下拉辅助文本”“上拉辅助文本”，显示数量、时间或其它说明。辅助文本默认空，不由组件自动生成或更新。所有文本设置为空时隐藏对应文字；处理中修改文案立即生效，不改变操作状态。文案按单行显示，过长时省略。

构建使用公共 `libraries/build.bat`，发布使用 `libraries/release.bat`。独立示例见 [sample/](sample/)，运行仅依赖 Simple 运行库与 Android 系统，资源使用 `es4a_pullrefresh_` 前缀。
