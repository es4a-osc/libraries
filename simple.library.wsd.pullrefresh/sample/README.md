# 拉动刷新框示例

先构建并安装本库，再使用对应 SDK 编译运行本项目。

主页面直接演示容器内的普通文本内容：在顶部下拉同步，在底部上拉追加 5 条记录。用计时器模拟两秒业务处理，完成后调用 `停止刷新()`；实际项目应把耗时业务放在后台，回到主线程更新界面。

“允许下拉”“允许上拉”两个复选框直接对应组件开关，取消勾选会结束该方向的当前等待。示例显式设置复选框文字垂直居中。

点击“设置文案”弹出列表，选择上下拉任一提示、释放、处理或辅助文本，输入框会预填当前值。确认后立即写入，取消保留原值，留空隐藏对应文字；在同一页面拉动即可查看效果。列表末尾可恢复默认文案。

提示、释放、处理文本分别用于未达阈值、达到阈值等待松手、进入刷新等待三个阶段。辅助文本可填时间、数量或任意说明，示例不会在业务完成时自动覆盖它。

`主窗口.simple` 包含主要演示逻辑，`文案输入框.simple` 仅提供弹出输入框的内容，不是独立设置页面。
