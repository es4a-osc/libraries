# 智能刷新框库

基于 SmartRefreshLayout 的下拉刷新、上拉加载容器，提供全部内置头尾样式、二楼、可定制头尾、完整外观快照、拖动与阶段事件、固定视图、边界判断及回弹曲线。

只允许一个直接可视子组件：列表框、网页浏览框或垂直滚动框可直接作为内容，多个普通控件放入内容容器。不额外包装滚动层；宿主窗口应关闭自身滚动，并为刷新框安排明确的可用高度。

所有成员在主线程调用。开始事件提供请求序号，业务完成后将同一序号传给 `完成刷新` 或 `完成加载`；返回假表示该请求已失效、已提交或方向不符。切换窗口或视图移出界面会取消当前请求并触发 `操作取消`，不会取消应用自己的任务。组件销毁时不再发送事件，应用应自行停止任务。完成成功的刷新会重置无更多数据状态。

使用 [运行示例](example/project.properties) 查看滚动内容、列表、本地网页、全部样式与高级选项。上游采用 `3.0.0-alpha`；源码形式提供的动画头保留在 `vendor/SmartRefreshLayout/`，仅调整本库资源索引引用，保留上游原许可证和作者信息。

头尾通过类型常量选择。使用 `取刷新头外观()` 或 `取加载尾外观()` 取得配置，修改后再应用；配置对象及数组均按快照复制。应用外观快照、切换样式和更改结构须在空闲时执行。虚拟头尾用于占位和回弹；飞行样式须先绑定“飞行场景”和图标组件。二楼通过独立可视组件提供内容，可在准备打开事件中拒绝进入。

自定义头尾可配置拖动背景和打开期间的内部触摸；适应内容高度时可请求重新测量。外观支持独立复制，Material 圆盘、波浪阴影及飞行场景视口可分别配置。

自定义头尾、二楼及临时替换内容采用同窗口借用，替换样式或销毁时归还原父容器和布局参数。固定头尾须在刷新框首次附着前配置，目标必须位于内容子树；固定包装生效后不支持替换整个内容。使用窗口初始化事件进行这些初始配置。

延时触发可以取消；仅动画模式不发出业务开始事件，使用 `关闭头尾()` 收回。拖动事件的距离和高度以像素报告，配置中的尺寸一般使用 DIP，字号使用 SP，时间使用毫秒。自定义边界和插值事件同步执行，应避免耗时业务。原生 View、Kernel 及 Java 监听器不作为 Simple 类型直接暴露，相应能力通过组件、配置对象和事件使用。
