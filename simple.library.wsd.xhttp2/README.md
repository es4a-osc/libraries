# XH2网络库

基于 [XHttp2](https://github.com/xuexiangjys/XHttp2) 封装，提供请求与响应处理、上传下载、进度、缓存、Cookie、证书、代理和批量请求。

需要 Android 7.0（API 24）及以上和 AndroidX。客户端在所属窗口显示后发送请求，事件在界面线程分发；离开窗口取消任务，销毁后不可复用。同步发送只能在工作线程调用。

内存响应默认最多 8 MiB。下载相对路径以应用私有 files 目录为基准，绝对路径须可写；下载校验后原子替换，失败保留原文件。上传文件、证书及文档 URI 须具备读取授权。

缓存容量须在首次使用会话前设置；同名活动会话的容量与 Cookie 持久化设置须一致。双发缓存策略可返回两份响应。证书链和主机名保持严格校验，代理支持 HTTP Basic 认证和无认证 SOCKS。自定义 CA、PKCS12 客户端证书及代理须提供实际可用配置。
