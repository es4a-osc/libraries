# 无障碍服务库

提供系统无障碍服务、类型化节点与窗口、事件、节点动作、多点手势、放大和软键盘控制，以及辅助按钮、指纹手势和字幕首选项读取。

Android 7.0（API 24）及以上可用，部分成员需要更高系统版本，具体条件随成员说明提供。使用服务前须在系统设置中手动启用本应用；节点读取和动作结果受目标界面公开的信息及系统限制影响。指纹手势需要受支持的硬件，辅助按钮受系统导航模式限制。

节点、窗口、列表和独立事件副本使用后须释放。回调事件仅在该次回调中有效，需要保留时先调用“复制事件”。组件和控制器在主线程使用，退出窗口不会撤销系统服务授权。

[运行示例](example/project.properties)：主窗口提供授权和导航，节点与窗口、事件与配置、屏幕手势、系统能力读取、通知监听分别在独立窗口演示。示例的通知发送端复用 SDK 中的状态条通知库，需要同时安装 `simple.library.wsd.notification`。
