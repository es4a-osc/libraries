# Lua脚本示例

演示 Lua **5.1.5** 的实例、函数、表、宿主回调及堆栈。需要支持 32 位 ARM 的设备；无需在设计器中放置 Lua 组件。

运行项目后从目录进入对应页面，各页可通过“返回目录”或系统返回键退出并释放解释器。

| 页面 | 操作与预期结果 |
| --- | --- |
| [代码与文件](src/simple/library/wsd/lua/sample/代码文件窗口.simple) | 编辑代码后直接执行，或写入应用私有文件再执行；默认返回文本、42、真和 nil。 |
| [函数调用](src/simple/library/wsd/lua/sample/函数调用窗口.simple) | 输入两个数值，对比直接调用和函数引用调用；默认 3、5 返回 8、15、nil。 |
| [表读写](src/simple/library/wsd/lua/sample/表操作窗口.simple) | 创建表，读取、修改或删除文本键，遍历数值键及嵌套的 address.city；默认 4 个键，数组长度为 2。 |
| [Lua 调用 Simple](src/simple/library/wsd/lua/sample/宿主回调窗口.simple) | 注册 hostAdd，Lua 调用 Simple 后返回 8 和说明文本；注销后全局值为 nil。 |
| [堆栈与生命周期](src/simple/library/wsd/lua/sample/堆栈生命周期窗口.simple) | 创建实例、压栈、弹栈及检查高层调用的栈平衡；保留引用在弹栈后有效，关闭实例后失效。 |
| [辅助自检](src/simple/library/wsd/lua/sample/自检窗口.simple) | 独立验证类型转换、二进制、表、回调错误、栈平衡和引用边界，失败时显示阶段。 |

[宿主加法](src/simple/library/wsd/lua/sample/宿主加法.simple) 继承 Lua回调，只演示正常业务逻辑：从位置 1、2 取参数，压入结果并返回结果数量。回调堆栈仅在本次调用有效，不能保存起来或在回调中关闭实例。故意出错的回调独立放在自检中。

每个返回的 Lua值 都需要释放，包括 nil 和转为表、函数后新取得的引用。高层调用恢复原栈；关闭实例会使全部引用失效。代码、函数及回调演示失败时关闭当前实例，修改输入后可重新执行。

文件页写入当前代码到应用私有的 lua-sample.lua，不需要存储权限；执行文件接收真实文件路径，不能直接传入 APK 内的资产名称。该文件保留供重复演示，下一次执行覆盖。

仅运行可信脚本。当前原生库只有 32 位 ARM，模拟器需要相应转译能力；仅有 64 位 ABI 的设备不可使用。详见[类库说明](../README.md)。
