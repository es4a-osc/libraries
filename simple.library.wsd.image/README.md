# 图像操作库

提供静态对象 `simple.library.wsd.image.图像操作`，包含旋转、倾斜、缩放、镜像、尺寸读取、压缩、切割、圆角、倒影、局部截取和相册扫描请求，无第三方 JAR 依赖。使用方式见[独立示例](sample/)。

- 图片字节集是 PNG、JPEG 等文件内容，不是原始像素数组。尺寸、坐标和半径都按图片像素计算，大图建议在后台线程处理。
- 文件尺寸读取接受资产名或以 `/` 开头的绝对文件路径；文件压缩和相册扫描使用绝对路径，不支持网址或 `content://`。访问公共存储仍受 Android 权限与存储规则限制，本库不自动申请权限。
- 除文件压缩外，图像变换均返回 PNG。`压缩图片` 中间使用 JPEG 降低画质，最终仍为 PNG，会丢失透明度且不保证文件变小；质量降到 0 后停止重试。`压缩图片2` 通过目标高度估算采样率，写出 JPEG，不保证精确目标尺寸。
- 镜像方向 0 为左右、1 为上下，其他值原样返回。切割按行排列，不能整除的右侧和底部像素丢弃。圆角参数达到 100 时转为居中圆形；倒影保留原画布高度和 4 像素间隔。
- 无效图片、非正尺寸及越界截取会抛出异常。尺寸读取打开失败返回 0，无法识别的图片返回 -1。`更新系统相册` 只提交异步扫描请求，不把私有图片发布到公共目录，也不保证图库立即可见。

示例自带确定生成的四色图片，输出仅保存在应用私有目录。已通过 Java 构建、JavaDoc 与清单校验、示例 APK 编译及 Android 14 / API 34 模拟器验证；69 项像素对照与边界检查通过。相册实际入库和真机表现尚未验证。

图标使用 [Tabler Icons](https://github.com/tabler/tabler-icons) 的 photo，MIT 许可文本见 `icons/LICENSE.txt`。
