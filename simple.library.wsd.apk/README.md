# APK信息库

提供普通对象 simple.library.wsd.apk.APK信息，先用“创建 APK信息”建立实例，再调用“解析(路径)”。成功后读取应用名称、包名、版本名、长整数版本号和图标字节集；使用方式见[独立示例](sample/)。

- 每次显式调用解析才读取本地 APK；所有属性只读取对象自身的快照，图标返回独立 PNG 字节副本。原文件删除、替换或系统语言变化后，旧快照保持不变，需重新解析才能更新。
- 解析同步完成，大文件应由调用方放在后台线程。为隔离 Android 同路径资源缓存，每次解析会将原文件流式复制到独立的私有临时 APK，完成后删除；需要额外的复制时间及临时空间。清理失败会报告错误，遗留文件位于应用 cache 目录。公开调用按对象串行处理；读取多个属性期间应避免同时发起下一次解析。失败清空旧结果并设置错误信息；清空只释放快照，不删除文件，之后可以再次解析。
- 相对路径以应用私有 files 目录为基准；绝对路径需已有读取条件。不直接接收 content URI、网址或资产名。系统文档选择返回 URI 时，先通过文件选择器复制到私有目录。
- 图标由平台 Drawable 绘制为最长边不超过 256 像素的 PNG，保留透明度；不等同于提取 APK 内原始图标文件。没有声明图标时使用平台默认应用图标。对象不保留 Activity、Drawable、Bitmap 或文件句柄。
- Android 9.0 起读取包含 versionCodeMajor 高位的完整版本号，旧系统采用平台提供的低位版本号。名称、资源及支持的 APK 格式由当前 Android 平台决定。
- 面向独立 APK，不支持 APKS、XAPK 容器或拆分 APK 组合。读取信息不代表完成签名校验，也不判断安装兼容性；本库不安装、不启动 APK，不枚举已安装应用。

无需第三方 JAR 或原生库，也不声明广泛存储、应用安装或应用列表查询权限；示例通过系统文件选择获得所选文档的访问授权。普通对象没有设计器组件节点。
