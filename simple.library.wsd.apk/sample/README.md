# APK信息示例

选择一个独立 APK，展示应用名称、包名、版本与图标；验证一次解析后的快照读取。需要 Android 4.4 或更高版本使用系统文档选择器。

在 ES4A 添加 [project.properties](project.properties)，安装本类库后编译运行。源码：[主窗口](src/simple/library/wsd/apk/sample/主窗口.simple)。对象 API 和限制见[类库说明](../README.md)。

1. 在设备中准备独立的 .apk 文件，点击“选择并解析APK”。系统只授权选中的文档；取消选择不会清空已有结果。
2. 选择器把文档复制为本应用私有 apk-info-import.apk，后台解析后显示名称、包名、版本及图标，原始文档不会修改。
3. 点击“显示缓存信息”，直接读取对象保存的值和已导出的 PNG，不再次解析原 APK。
4. 点击“验证缓存与清空”，执行 22 项断言：PNG 签名和数组副本、删除私有 APK 后快照仍可读、重新解析缺失文件失败并清空旧结果、显式清空恢复初始状态。最后删除本例的私有副本及 PNG，不删除原文档。
5. 点击“清空信息与导入副本”，清空对象和本例的私有副本；再次选择 APK 即可重新解析。

复制、解析和 PNG 保存均在后台执行，完成后通过反馈消息刷新界面；处理期间暂停这些按钮。示例不保存文档的持久访问授权，不安装选中的 APK，也不申请广泛存储权限。复制或解析失败时显示错误，不展示旧信息。
