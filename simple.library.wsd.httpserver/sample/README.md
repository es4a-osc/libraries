# HTTP / WS服务样例

构建并发布 HTTP 服务库到所选 SDK 后，运行本项目，点击“启动监听（5000）”。同一个端口提供 HTTP 请求响应和 WebSocket 文本回显，不依赖外部网络接口。

| 地址 | 行为 |
| --- | --- |
| `http://服务端IP:5000/` | 返回请求方式、路径和服务端时间；其它 GET、POST 路径也使用此响应。 |
| `http://服务端IP:5000/yy` | 返回本地文本“让编程更简单。”。 |
| `ws://服务端IP:5000/ws` | 连接后发送欢迎消息，收到文本时原样回传。 |

与 [WS客户端样例](../../simple.library.wsd.wsclient/sample/) 交互时，将客户端的连接地址改为 `ws://服务端IP:5000/ws`，连接成功后发送文本，即可观察双方日志和回显。关闭客户端连接后，服务端记录关闭事件。

同机应用之间可使用 `127.0.0.1`；不同设备应处于可互通的网络，填写服务端设备的局域网 IP。不同模拟器各自拥有独立回环地址。本样例提供 `ws://`，没有配置 TLS。

“停止监听”只停止接受新连接，已有 WS 连接仍由客户端主动关闭。HTTP、WS 回调在网络线程执行，样例通过窗口的 `投递消息` 更新界面日志。

现有依赖 AndroidAsync 2.2.1 在收到 WS 关闭帧后直接断开 TCP，没有应答关闭帧。与当前 WS 客户端互测时，主动关闭会触发客户端“出现错误”；服务端仍收到关闭回调。连接和文本回显可正常测试，完整关闭握手仍有此兼容性限制。
