# MPAndroidChart图表库示例

使用公共 `libraries/build.bat` 构建本库，再通过 `libraries/release.bat` 安装到当前 SDK，编译运行本项目。应用使用默认图标，不需要网络权限。

- 顶部九个按钮切换九种图表：折线显示高低温两个数据组并使用左右轴；柱图、横向柱图和雷达图使用两组数据；组合图包含折线、柱状、散点、气泡和蜡烛五组数据。
- 点击数据点或扇区，底部文字显示从零开始的数据组编号、项目索引和数值；蜡烛图返回收盘值。重复点击同一高亮项目可取消选择。
- “重复构建”不应增加数据或扩大轴范围。“清空图表”应显示暂无数据；“恢复数据”恢复全部图表。
- “平滑曲线”切换折线效果并显示当前状态。“无效数据”拒绝负数饼图项，已有三个扇区应保持不变。

“边界数据”显示全零雷达图，刻度应保持有效；切换到气泡图时零大小气泡应不可见。“恢复数据”恢复正常数据。

`准备数据` 展示完整调用顺序；传入数组由组件复制。更换项目名称前先清空数据。测试直接在本示例中进行，按上述操作检查图形、事件和数据校验结果。
