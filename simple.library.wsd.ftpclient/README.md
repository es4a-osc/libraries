# FTP客户端

提供独立的“FTP客户端”“SFTP客户端”非可视组件，以及 `FTP远程文件` 快照、FTP 分页、常量、错误和受控数据流对象。

FTP 的连接与登录分开，默认使用被动模式、二进制和 UTF-8；支持主动模式、控制命令、结构化列表、文件流及上传下载。分页是已取得列表的本地游标。SFTP 要求 Android 8.0 及以上，连接时同时完成认证。

SFTP 首次连接须核实并确认服务器公钥，后续连接自动校验已保存的记录；公钥变化时需重新确认。也可指定可信的服务器公钥指纹进行严格校验。

同步网络、流读写及流关闭须在后台线程串行调用；打开 FTP 数据流会独占连接，读到末尾后仍须关闭，关闭时核对服务器最终答复。一个组件只处理一项任务，异步方法返回受理编号，实际进度和终态通过界面线程事件报告。

取消文件任务会断开连接；重新连接后可用偏移续传。源文件和已有前缀须保持一致，本库不自动核对前缀摘要。FTP 偏移续传仅用于二进制模式；文本转换模式的进度总量为 `-1`。下载经服务器确认后才替换目标，失败或取消保留本实例断点；销毁会清理断点，不支持进程重启恢复。目录传输要求目标目录不存在，拒绝链接，失败可能留下部分内容。

本地相对路径以应用私有 `files` 目录为基准；绝对路径访问范围由应用权限决定。客户端销毁或宿主结束会释放连接；切换窗口时若要结束任务，应显式销毁客户端。

## 依赖来源

- [Apache Commons Net 3.6](https://commons.apache.org/proper/commons-net/)：FTP 支持。
- [维护版 JSch 2.28.8](https://github.com/mwiede/jsch)：SFTP 支持，使用 Android 适配版本。

[FTP客户端示例](example/project.properties)按连接、文件管理、传输、流与分页、SFTP 分主题展示用法；服务器、账号和必要条件在示例中填写及说明。
