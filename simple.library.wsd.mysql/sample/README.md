# MySQL数据库示例

文档类型：使用示例。核对日期：2026-10-15。依据：本库公开接口、`library.json`、原例程以及当前 Simple 编译器和运行库。适用范围：本目录的 `project.properties`。

先构建本库；实际使用时通过类库仓库 `release.bat` 安装到选用的 SDK，再在 ES4A 中选择该 SDK 入口、刷新类库并添加本目录的 `project.properties`。本次构建验证使用隔离的类库目录，没有修改 SDK 安装目录或入口。

1. 将预留示例地址 `192.0.2.1:3306`、库名、用户名和密码改为自己的测试数据库。示例不保留原工程账号。
2. 点击连接，成功后执行默认 `SELECT 1 AS value`，日志按“集合 → 文本数组”显示查询结果。
3. 若要体验原库增删改，先在测试库中手动创建下方 `es4a_demo` 表；三个按钮只操作该表的 `id=1`。
4. 新增后将查询框改为 `SELECT id,name FROM es4a_demo` 查看，再分别修改、删除。每次操作通过对应完成事件返回。
5. 点击断开。

```sql
CREATE TABLE es4a_demo (id INT PRIMARY KEY, name VARCHAR(64));
```

SQL 和条件片段沿用原接口，不自动绑定或转义参数，不要直接拼入外部输入。同步方法只供工作线程使用。没有参数化查询或事务的新承诺。

已验证：Java 构建、清单加载、成员与继承、签名、SVG 和设计器候选消费、真实 Simple 示例生成 APK。未验证：真实扩展宿主可见交互、Android 真机及实际设备或服务器行为。
