# ACE图表库

基于 [AChartEngine](https://github.com/ddanny/achartengine) 封装，提供折线、平滑曲线、时间、柱状、区间柱、散点、气泡、组合、饼状、圆环和仪表盘十一类图形，支持多数据组、左右轴、样式、缺失项目、数据更新、选择、拖动缩放及 PNG/JPEG 字节导出。

需要 Android 7.0（API 24）及以上，图表在界面线程操作。先初始化，再添加数据并构建；刷新保留当前可见范围。配置与数组应用时复制，导出和坐标换算须等待绘制完成。数值横坐标必须严格递增且不重复；数据绝对值不超过 `1e99`，轴界限不超过 `1e100`。时间图使用整数毫秒时间戳，按设备时区显示。

饼图和圆环数值非负且至少一个正数；仪表指针须在设置的量程内。气泡沿用上游的最小半径。柱的重叠模式从零点覆盖绘制，不是累加堆叠。圆环与仪表盘仅支持主动选择；选择以文字提示呈现，上游没有程序化高亮。底层 Android 绘制对象不作为 Simple 接口导出。

依赖随库携带的 AChartEngine 1.0.0 JAR。
