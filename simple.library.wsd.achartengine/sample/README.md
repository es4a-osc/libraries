# AChartEngine图表库示例

先使用 `libraries/build.bat` 构建AChartEngine图表库，再通过 `libraries/release.bat` 发布到当前 SDK，打开本项目编译运行。应用使用 SDK 默认图标，无需网络或存储权限。

- 初始显示三个项目的饼状图，点击顶部按钮切换柱状图和折线图。
- “追加数据”向三种图表各加入一个项目；“重复构建”连续构建三次，画面数据和刻度范围应保持不变。
- “清空图表”重新初始化并构建空图，三种图形均应消失；“恢复数据”重新显示三个项目。
- “边界数据”展示单项目饼图，以及含正数、零和负数的柱状图、折线图；切换类型检查零线和负数位置。
- “无效数据”尝试加入负数饼图数据及非数值文本，界面应显示拒绝提示，已有图表应保持原样。

示例中的 `准备数据`、`构建全部` 和各按钮事件给出完整调用顺序。测试直接在本示例中进行，按上述操作检查图形、事件和数据校验结果。
